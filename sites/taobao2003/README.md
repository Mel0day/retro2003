# 淘宝网 2003（taobao2003）

> 本站是 [retro2003](../../README.md) 项目的一部分：用 2003 年的互联网形态复刻今天的主流产品。仓库根目录有两个站点一起跑的 Docker 编排。

一个 2003 年风格的 C2C 网上交易站：任何会员都能买，也能免费开店卖，支付宝担保交易，买卖双方互评信用。
界面按原型 `design/03 淘宝.dc.html` 复刻：778px 橙色主题、跑马灯公告、闪烁 new!、黑底绿字访问量计数器，正文使用 2003 年的点阵宋体。

> 站内的支付宝是演示用的虚拟资金：新会员注册送 1000 元体验金，只能在站内购物，不能充值提现，不涉及真实支付。

## 快速开始

```bash
npm install
# 本地预览（导入演示数据）
DATA_DIR=./data SEED_DEMO=true ADMIN_USERNAME=淘宝小二 ADMIN_PASSWORD=改成12位以上的密码 npm start
# 打开 http://localhost:3004
npm test          # 80 项集成测试
npm run test:e2e  # 5 项浏览器端到端测试（需要 Chromium，见下）
node scripts/crawl.mjs http://127.0.0.1:3004 demo demo1234   # 爬站自检：404/500、模板残留
```

本机没有 playwright 自带浏览器时，`test/e2e/helpers.js` 会自动找 `~/Library/Caches/ms-playwright` 里缓存的 chrome-headless-shell，也可以用 `PW_CHROMIUM=/path/to/chrome-headless-shell` 指定。

## 功能说明

### 买东西
1. 列表和搜索：搜索忽略大小写、全角和标点，「哈利波特」能搜到「哈利·波特与凤凰社」；多个关键词取交集；关键词在标题和描述里高亮。
2. 加入购物车：游客也能加（按访客 cookie 保存），登录时自动合并到账号，数量不超过库存。购物车按卖家分组，下架、卖完、自己发布的宝贝会标出来并在结算时跳过。
3. 「立刻购买」不经过购物车，直接进入确认订单页。
4. 确认订单：地址簿一键填入，按卖家分别选平邮（免费）或 EMS（20 元），页面上运费和应付总额随选择即时变化；提交时服务端再算一遍，和页面显示不一致（比如卖家刚改了价）会拒绝下单。
5. 付款：扣支付宝余额，按卖家拆成多张订单，扣库存、加销量、清购物车、保存收货地址，全部在一个事务里完成。余额不足或库存不足都会拦住，两个人抢最后一件只有一个能成功。

### 卖东西
1. 「我要卖」填写分类、标题、描述、标签、一口价、原价、库存、所在地、详情，最多传 3 张图片（按文件头识别 JPG/PNG/GIF/WEBP，单张 2MB）。可以直接上架，也可以先放仓库。
2. 出售中 / 仓库中的宝贝：编辑、上下架、删除。有未完成交易的宝贝不能删除；删除是软删除，历史订单里的交易快照仍然完整。
3. 已卖出的宝贝：买家付款后发货（填物流公司和运单号），缺货时可以关闭交易并退款。
4. 宝贝留言：买家在宝贝页公开提问，卖家在「我的淘宝 → 宝贝留言」回复，回复显示在宝贝页。

### 交易与信用
- 状态流：买家已付款 → 卖家已发货 → 交易成功；未发货前买家可取消、卖家可关闭，货款原路退回支付宝、库存退回。
- 卖家发货后 10 天买家不确认，系统自动确认收货（`AUTO_CONFIRM_DAYS` 可调）。
- 确认收货后货款才打给卖家，支付宝账户明细里每一笔进出都有记录。
- 交易成功后双方互评：好评 +1、中评 0、差评 -1；中评差评必须写原因；被评价方可以解释一次。
- 同一会员 30 天内对同一对象的重复评价只计一次信用分（防刷信用），评价内容仍然展示。
- 信用等级按 2003 年淘宝的心、钻划分：4-10 分 1 心 … 151-250 分 5 心，251 分起是钻。列表页沿用原型的 ★ 表示心级。

### 淘宝小二后台（`/admin`，需要 role=admin 的账号）
统计首页（会员、宝贝、交易、成交额、担保中资金、近 7 天下单、分类成交、成交额最高的卖家）、会员管理（搜索、冻结/解冻，冻结后立即下线且宝贝对买家隐藏）、宝贝管理（搜索、按状态筛选、强制下架并填原因、恢复）、交易管理（搜索、按状态筛选、纠纷处理：关闭未完成交易并全额退款、退回库存）、评价与留言（屏蔽违规内容，不改动信用积分）、站点设置（公告、广告位文字与链接、热门搜索词、计数器基数、开放注册、客服信箱、备案号）。

## 数据模型

| 表 | 说明 |
| --- | --- |
| `users` | 会员（买家卖家同一账号）：会员名（唯一，不区分大小写）、scrypt 密码散列、role、所在地、店铺介绍、支付宝余额（分）、冻结状态 |
| `sessions` | 会话：存令牌的 sha256，14 天记住登录 |
| `items` | 宝贝：分类、标题、描述、标签、一口价/原价（分）、库存、已售、所在地、详情、图片（JSON 数组）、状态（onsale/warehouse/deleted）、小二下架标记、搜索归一化文本、浏览数、上架时间 |
| `carts` | 购物车：owner_key（`u:会员id` 或 `v:访客id`）+ 宝贝 + 数量 |
| `orders` | 订单：订单号 TB+8 位、买家、卖家、货款、运费、总额、收货信息、状态、物流、关闭原因、各状态时间戳、自动确认时间 |
| `order_items` | 交易快照：下单时的标题、分类、图片、单价、数量 |
| `order_logs` | 交易记录（谁在什么时候做了什么） |
| `ratings` | 信用评价：订单、宝贝、身份（评卖家/评买家）、评价人、被评价人、好中差、内容、解释、是否计分、是否被屏蔽 |
| `questions` | 宝贝留言与卖家回复 |
| `favorites` `addresses` `alipay_logs` `settings` | 收藏夹、收货地址簿（最多 8 条）、支付宝账户明细、站点设置 |

金额一律用「分」保存的整数，页面统一显示两位小数。

## 安全

- 所有 POST 走 CSRF（HMAC(密钥, 访客 id)），只认表单字段 `_csrf` 或请求头 `X-CSRF-Token`，不认 URL 参数。
- 模板默认转义；富文本只有换行转 `<br>`；搜索高亮在原文上匹配后分段转义。
- 全站 CSP（`script-src 'self'`、`object-src 'none'`）、nosniff、X-Frame-Options、Referrer-Policy。
- 所有 SQL 参数化，`LIKE` 转义；搜索归一化时就去掉了通配符。
- 越权：订单、地址、宝贝、留言、评价都校验归属；别人的订单一律 404，不泄露订单号是否存在。
- 会员名 NFKC 归一化 + 大小写不敏感唯一，保留字（淘宝、小二、客服、管理员…）不能注册。
- 限速：登录 20 次/10 分钟/IP，注册 5 个/小时/IP，下单 20 次/10 分钟，留言、改密、地址等都有上限。
- 上传按文件头识别图片类型，不信任扩展名，不接受 SVG；上传目录只提供静态图片，不可列目录。
- 站长密码只从环境变量读，scrypt 散列存库；改密后其它设备会话全部失效。

## 部署

### Docker（推荐）

```bash
cp .env.example .env   # 至少改 ADMIN_PASSWORD、SESSION_SECRET
docker compose up -d --build
# 首次要导入演示数据就把 .env 里的 SEED_DEMO 改成 true，导入后改回 false
```

数据在命名卷 `taobao-data`（SQLite 库 + 上传的图片 + 备份）。前面挂 Nginx 时参考 `deploy/nginx.conf`（注意 `client_max_body_size` 至少 8m，否则传图会失败）。
走 Cloudflare Tunnel 的线上部署见 `deploy/cloudflare/README.md`。

### 备份

```bash
docker exec taobao2003 npm run backup   # SQLite 在线备份到 /data/backups，保留 14 份
```

上传的图片在 `/data/uploads`，备份脚本会输出一份清单，请把整个数据卷一起打包备份。

### 环境变量

见 `.env.example`。常用：`ADMIN_USERNAME` / `ADMIN_PASSWORD`（首次启动创建站长）、`SESSION_SECRET`、`TRUST_PROXY`、`SEED_DEMO`、`NEW_MEMBER_YUAN`、`AUTO_CONFIRM_DAYS`、`PORT`、`DATA_DIR`。

## 测试

- `npm test`：80 项集成测试，覆盖注册登录、列表搜索、购物车、结算下单、交易状态流、信用评价、卖家发布与管理、后台、安全（CSRF/XSS/越权/注入/限速）、演示数据与重启持久化。
- `npm run test:e2e`：5 项浏览器测试，走完「卖家发布带图宝贝 → 买家下单 → 卖家发货 → 买家确认收货 → 双方互评」、游客购物车合并、取消订单退款、后台操作，并断言控制台零报错。
- `node scripts/crawl.mjs <地址> [会员名 密码]`：按身份爬遍站内链接，报告 404/500、慢页面和模板残留。

## 与原型的差异

| 原型 | 本站 | 原因 |
| --- | --- | --- |
| 卖家只是宝贝上的一个名字 | 卖家是会员账号，任何人都能开店 | 2003 年的淘宝是 C2C 平台，不能只有买的一半 |
| 点「加入购物车」后直接下单 | 多了注册、支付宝余额、发货、确认收货、互评 | 让交易闭环真实可用 |
| 星级是写死的 | ★ 由真实信用积分换算（心级），店铺页显示好评率和最近一周/一月/全部的好中差 | 和 2003 年淘宝的信用体系一致 |
| 宝贝图片是斜纹占位 | 演示宝贝配了真实照片（Unsplash，署名见 `seed/images/credits.json`），卖家可以自己上传 | 让首页像运营了两年 |
| 只有前台 | 增加淘宝小二后台 | 上线需要内容管理和纠纷处理 |

## 已知限制

- 支付宝是模拟的：没有真实支付、没有充值提现、没有退款到银行卡。
- 物流是手填的单号，没有对接真实物流查询。
- 没有站内信和即时聊天（旺旺是 2004 年才有的），买卖双方通过宝贝留言沟通。
- 没有拍卖（一口价之外的竞价）、没有类目属性和多规格（尺码颜色靠标题和留言约定）。
- 全站统一运费（平邮免费 / EMS 20 元），卖家不能自定义运费模板。
- 搜索是 SQLite LIKE，数据量大时需要换成全文索引。
- 没有找回密码流程，忘记密码要联系客服（小二可以用 `npm run create-admin` 重置站长密码）。
- 「淘宝」「支付宝」是阿里巴巴的注册商标，本站是复刻演示，正式对外上线请改名并处理备案。
