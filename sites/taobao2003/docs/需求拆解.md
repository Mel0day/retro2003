# 淘宝网 2003：需求拆解与产品设计

原型：`design/03 淘宝.dc.html`（列表、详情、购物车、登录、结算、成功页、我的订单七个视图）。
原型只画了「买」的一半，本站按 2003 年淘宝的真实形态补齐了「卖」的一半和交易闭环。

## 一、产品定位

2003 年的 C2C 个人网上交易平台：任何会员免费开店卖东西，也可以买东西；支付宝担保交易（买家付款到支付宝，确认收货后货款才打给卖家）；买卖双方互评信用，信用用心和钻表示。

刻意不做的（2003 年还不存在或与定位无关）：即时聊天工具（旺旺是 2004 年）、扫码支付、手机验证码、个性化推荐、直播、拍卖竞价、类目属性与多规格。

## 二、角色与主要场景

| 角色 | 场景 |
| --- | --- |
| 游客 | 逛列表、搜索、看详情和店铺、加购物车（登录后合并）、注册 |
| 买家 | 加购物车 / 立刻购买 → 填地址选配送 → 支付宝付款 → 等发货（可取消）→ 确认收货 → 评价卖家；收藏夹、地址簿、支付宝明细、给卖家留言 |
| 卖家 | 发布宝贝（带图）→ 管理出售中 / 仓库中的宝贝 → 买家付款后发货（或缺货关闭）→ 交易成功收款 → 评价买家；回复宝贝留言、店铺介绍 |
| 淘宝小二 | 统计、冻结会员、强制下架违规宝贝、纠纷处理（关闭交易并退款）、屏蔽违规评价与留言、站点设置 |

## 三、交易状态机

```
           买家付款（扣支付宝余额、扣库存）
                      ↓
  ┌──────────── 买家已付款(paid) ─────────────┐
  │ 买家取消 / 卖家缺货关闭 / 小二处理        │ 卖家发货（填物流公司、运单号）
  ↓                                           ↓
交易关闭(closed)                        卖家已发货(shipped)
  · 货款退回买家支付宝                        │ 买家确认收货 / 10 天后系统自动确认
  · 库存、销量退回                            ↓
                                        交易成功(done)
                                          · 货款打给卖家
                                          · 双方可以互评
```

规则：
- 每个状态的操作都用「WHERE status = 旧状态」的条件更新，重复提交、并发点击只会生效一次。
- 发货后买家不能取消、卖家不能关闭；纠纷由小二处理（可以关闭已发货的交易并退款）。
- 交易成功和交易关闭是终态，不能回退（避免「关闭后再恢复」导致超卖）。
- 一次结算按卖家拆成多张订单，每张单独计运费、单独发货、单独评价。

## 四、信用评价

- 交易成功后，买家评卖家、卖家评买家，各一次；好评 +1、中评 0、差评 -1；中评差评必须写原因（≥5 字）；被评价方可以解释一次。
- 防刷：同一评价人对同一会员（同一身份）30 天内只有第一条计入信用积分，其余照常展示但标「不计分」；不能购买自己发布的宝贝。
- 信用等级（沿用 2003 年淘宝）：4-10 分 1 心、11-40 分 2 心、41-90 分 3 心、91-150 分 4 心、151-250 分 5 心；251-500 分 1 钻，以此类推。原型列表页的 ★ 就是心级。
- 好评率 = 好评数 ÷ 计分评价总数；店铺页另给出最近一周 / 一月 / 全部的好中差三档统计。
- 小二只能屏蔽评价内容，不能改积分，保证信用不可被运营随意修改。

## 五、支付宝（演示资金）

真实支付不可能做，但「担保交易」是 2003 年淘宝的灵魂，所以用站内虚拟余额模拟：

- 新会员注册送 1000 元体验金（`NEW_MEMBER_YUAN`），不能充值、不能提现。
- 付款时从买家余额扣除，记一条支付宝明细；交易成功时打给卖家；交易关闭时原路退回。
- 「担保中」的钱在买家和卖家的支付宝页面都能看到（我付出的 / 待收款的）。
- 副作用：余额天然限制了恶意下单的规模，配合注册限速（5 个/小时/IP），刷单只能刷到有限次数。

## 六、与原型的取舍

1. **保留原型的视觉**：778px、橙色导航、搜索框、跑马灯、左栏分类与价格区间、120×90 广告位、表格列表、渐变按钮、闪烁 new!、黑底绿字计数器、页脚版权与备案号。新增页面（我的淘宝、发布宝贝、店铺、后台）全部复用这套元素。
2. **补齐 C2C**：卖家账号化、我要卖、卖家发货、买家取消、双向评价、店铺页。
3. **补齐可用性**：注册页（原型只有登录）、收藏夹、收货地址簿、宝贝留言、支付宝账户明细、交易快照。
4. **数据充实**：原型的 9 件宝贝全部收录并扩充到 35 件，14 位卖家、10 位演示买家、48 位历史会员、46 张订单、1800+ 条历史评价，卖家信用与原型上的星级对得上。

## 七、验收清单（对应自动化测试）

- 列表、分类、价格区间、排序、分页、搜索（标点大小写不敏感、多关键词、无结果）
- 详情：库存、卖家信用、评价、留言；仓库中的宝贝别人看不到
- 购物车：游客加购、登录合并、加减删、库存上限、跨账号隔离
- 结算：拆单、运费、余额、库存、地址簿、金额精度（分）、并发抢购只成一单、价格变动拒绝下单
- 交易：发货、确认收货、取消、卖家关闭、超时自动确认、越权一律 404
- 评价：只有交易成功能评、不能重复评、中差评要原因、30 天只计一次分、解释一次
- 卖家：发布（含图片）、校验、编辑、上下架、删除（有未完成交易不能删）、快照保留
- 后台：统计、冻结、强制下架、纠纷关闭退款、屏蔽评价、站点设置
- 安全：CSRF（含 URL 参数令牌无效）、XSS、越权、SQL/LIKE 注入、畸形参数、限速、响应头、错误页不泄露堆栈
- 数据：演示数据幂等、重启持久化、空库可用
