# 小红书 2003 · 需求拆解

原型：Claude Design 项目「小红书 2003 年风格重设」共三张稿。

| 设计稿 | 内容 |
| --- | --- |
| 小红书 2003 | PC 首页，778px 三栏门户 |
| 笔记详情 2003 | PC 笔记正文页，两栏 + 盖楼留言 |
| WAP 2003 | 手机 WAP 2.0 版首页和正文页，数字快捷键导航 |

目标：把原型里每一个「看起来能点」的元素做成真实可用的功能，前后端完整，可一条命令部署。

## 1. 页面与功能清单

### 1.1 公共框架（所有 PC 页）
- 顶部：站名 Logo、口号、468×60 横幅广告（后台可配置，彩虹动画或纯色两种样式，多条随机轮换）。
- 导航：首页 / 笔记 / 购物 / 论坛 / 相册 / 排行榜 / 聊天室 / 帮助，当前频道红色高亮。
- 导航右侧：首页显示日期 + 设为首页 / 加入收藏；内页显示「欢迎您，游客 [登录] [注册]」或「欢迎您，xx [控制面板] [短消息(n)] [退出]」。
- 跑马灯公告：后台维护多条，★ 分隔滚动，可整体关闭。
- 页脚：关于我们 / 广告服务 / 联系站长 / 诚聘版主 / 免责声明 / 网站地图，均为后台可编辑的单页；站长信箱、备案号来自站点设置。

### 1.2 首页
| 模块 | 数据来源 |
| --- | --- |
| 会员登录框 | 用户名 + 密码 + 图形验证码 + 记住我两周；已登录时变为「会员信息」卡片 |
| 频道导航 | 频道表，括号内为该频道已发布笔记数 |
| 站内搜索 | 笔记 / 用户 / 商品 三类 |
| 友情链接 | 后台维护 |
| 今日推荐笔记 | 后台「推荐」的带图笔记，不足 6 篇时按近期点击补齐 |
| 最新笔记 | 按发表时间，[图]/[文] 由是否含图决定，24 小时内显示闪烁 NEW |
| 好物推荐 | 商品表中后台推荐的商品 |
| 论坛热帖 | 按回复数 |
| 热门标签 | 按使用次数生成字号和颜色 |
| 人气排行 TOP10 | 笔记点击数，前三名红橙黄底 |
| 站长公告 | 站点设置 |
| 访客计数器 | 真实新访客累加 + 后台可设基数；当前在线为 15 分钟内活跃访客 |

### 1.3 笔记
- 笔记列表：按频道 / 标签 / 最新 / 最热筛选，分页。
- 笔记详情：面包屑、标题、作者 / 发表时间 / 点击 / 回复 / 频道。
- 工具条：收藏本文、打印版、举报、字体大中小。
- 正文：UBB 代码渲染，支持粗体、颜色、小标题、图片带说明、图文环绕、三栏图集、表格、有序列表、引用、链接。
- 顶一下（游客按访客 ID 限一次）、收藏（会员）、送花（会员每天每篇一朵，作者 +5 积分）。
- 上一篇 / 下一篇：同频道相邻笔记。
- 网友留言：楼层号、头像（首字 + 颜色或上传头像）、等级、分页、[回复] 自动 @、[引用] 插入 quote。
- 发表留言：游客填昵称 + 验证码，会员免昵称；表情点击插入；提交 / 重填。游客留言默认进审核队列，会员直接显示，后台可改策略。
- 右栏：作者资料（等级星、笔记数、积分、注册日期、来自、[短消息] [加好友] [TA的笔记]）、本文标签、相关笔记、本频道热门、160×100 广告位。
- 发表 / 编辑 / 删除笔记：UBB 工具栏、上传图片（前端先压缩再上传）、预览、频道、标签。

### 1.4 购物
- 商品分类列表、商品详情（价格 / 市场价 / 库存 / 销量 / 介绍）。
- 下单：收货人、电话、地址、数量、付款方式（货到付款 / 邮局汇款 / 银行转账），扣库存。
- 我的订单：查看状态、待确认时可取消。
- 后台：商品增删改、首页推荐、订单确认 / 发货（填快递单号）/ 完成 / 取消。

### 1.5 论坛
- 论坛首页：分区 → 版块，显示主题数、帖子数、最后发表。
- 版块页：置顶 / 精华标记，主题列表带回复数、点击数、最后回复。
- 帖子页：盖楼、分页、回复、引用；楼主可发投票帖（单选，每人一票，显示比例条）。
- 版主 / 站长：置顶、加精、锁帖、删帖。

### 1.6 相册
- 相册首页：最新照片墙、热门相册。
- 我的相册：建相册、上传照片（每人空间配额默认 20MB，单张上限可配），设封面、删除。
- 照片页：大图、上一张 / 下一张、点击数、文件大小。

### 1.7 排行榜
- 笔记点击榜 / 顶榜 / 送花榜，支持本周、本月、总榜。
- 会员积分榜、发帖榜，论坛热帖榜，商品销量榜。

### 1.8 聊天室
- 多个房间（大厅、穿搭、旅游、数码），实时消息（SSE 推送）。
- 在线名单、字体颜色、「对 某人 说」、动作表情。
- 游客可旁观，会员可发言；限速防刷屏；进出房间系统提示。

### 1.9 会员中心
- 注册：用户名、密码、确认、密码提示问题与答案、来自、验证码；同意服务条款。
- 登录 / 退出 / 记住我；忘记密码：用提示问题重置（无需邮件服务，贴合 2003 年做法）。
- 个人主页：资料、TA 的笔记、TA 的相册、TA 的好友。
- 控制面板：修改资料（头像上传或选色、签名、来自、性别）、修改密码、我的笔记、我的收藏、我的好友、积分记录、我的订单。
- 短消息：收件箱、发件箱、写信、未读数提示；系统通知（有人留言、送花、加好友）也以短消息形式送达。
- 积分与等级：发笔记 +10、被留言 +1、留言 +2、收到花 +5、每日首次登录 +5；新手上路 / 初级 / 中级 / 高级 / 资深 / 元老，站长可设自定义头衔。

### 1.10 搜索、标签、帮助
- 搜索结果页：三种类型切换，关键词高亮，分页。
- 标签页：该标签下的所有笔记。
- 帮助中心：新手指南、UBB 代码说明、积分等级说明、社区规则。

### 1.11 WAP 手机版（/wap）
- 首页：今日推荐、[1]~[4] 数字快捷入口（accesskey）、热门、登录 / 注册 / 电脑版、页面字节数 + 在线人数。
- 笔记正文分页阅读（第 1/4 页）、看全文、回复、顶、收藏、上一篇 / 下一篇。
- 最新笔记、频道、论坛、聊天室（刷新式）、相册、好物、我的小红书。
- 手机 UA 访问首页自动跳 WAP，点「电脑版」后记住选择。

### 1.12 站长后台（/admin）
- 概况：会员数、笔记数、今日新增、待审留言、待处理举报、待确认订单。
- 会员管理：搜索、设角色（会员 / 版主 / 站长）、封禁、改头衔、调积分。
- 笔记管理：推荐、隐藏、删除。
- 留言审核、举报处理。
- 频道、论坛分区与版块、聊天室房间。
- 商品与订单。
- 公告跑马灯、广告位、友情链接、单页内容。
- 站点设置：站名、口号、站长公告、站长信箱、备案号、计数器基数、显示开关、审核策略、上传限制。

## 2. 非功能需求
- 安全：scrypt 密码哈希、会话 Cookie 仅 HttpOnly + SameSite、所有表单 CSRF 校验、UBB 输出全部转义、上传按文件头校验类型、登录 / 注册 / 留言 / 聊天限速、封禁用户不可登录。
- 视觉：像素级还原原型的 778px 固定宽度、宋体 12px、渐变标题栏、Win2000 按钮等细节。
- 部署：单进程 Node + SQLite 单文件，Docker 一条命令启动，数据和上传文件挂载到一个目录，便于备份。
- 首次启动用环境变量创建站长账号；可选导入演示数据。

## 3. 技术方案
| 层 | 选型 | 理由 |
| --- | --- | --- |
| 运行时 | Node.js 22 LTS | 部署面最广 |
| Web 框架 | Express 5 | 成熟、异步错误自动捕获 |
| 模板 | Nunjucks 服务端渲染 | 2003 年门户本就是服务端渲染，SEO 友好，模板默认转义 |
| 数据库 | SQLite（better-sqlite3，WAL） | 零运维，单文件备份 |
| 实时 | Server-Sent Events | 聊天室单向推送足够，无需 WebSocket 依赖 |
| 前端交互 | 原生 JS 渐进增强 | 顶 / 收藏 / 送花 / 留言 / 编辑器 / 聊天 |
| 测试 | node:test 集成测试 + Playwright 端到端 | 无额外测试框架依赖 |
| 部署 | Dockerfile + docker-compose + Nginx 示例 | |

## 5. 已知限制

- 在线人数、验证码、限速计数保存在进程内存里，只适合单实例部署（SQLite 本身也是单机方案）。
- 投票只支持单选；好友是单向关注，没有申请审核流程；聊天室没有私聊、踢人和禁言。
- 「本周 / 本月点击榜」按发表时间筛选笔记，数值是累计点击，因为没有按天记录点击明细。
- WAP 版不支持投票、写短消息、下单和发笔记，页面上会引导到电脑版。
- 找回密码依靠密码提示问题，没有邮件或短信验证；上线后如果需要更强的账号安全，可以接入邮件服务。
- 后台替换广告图、商品图后，旧图片文件不会自动清理。
