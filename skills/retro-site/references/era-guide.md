# 1999-2005 的网页与产品形态

## 一、年份的差别

| 年份 | 页面宽度 | 典型特征 |
| --- | --- | --- |
| 1999-2000 | 760px 或自适应表格 | 纯 table 排版、动图分隔线、`<marquee>`、访客计数器、Frames 分栏、蓝紫色下划线链接、"Best viewed in IE5 800×600" |
| 2001-2002 | 760-778px | 三栏门户、渐变标题条、小圆点项目符号、GIF 按钮、弹窗广告、导航条用背景图 |
| 2003-2004 | 778-800px | 门户成熟期：圆角很少、渐变条 + 1px 边框、表格列表、页脚备案号、BBS 盖楼、WAP 手机版 |
| 2005 | 900px 左右 | Web2.0 苗头：圆角、渐变按钮、标签云、AJAX 局部刷新（当年叫「无刷新」）、RSS 橙色图标 |

## 二、当年就有的视觉元素（尽量用）

- 固定宽度居中，`table` 布局，`cellpadding`/`cellspacing`
- 标题条：纯色或竖向渐变，左侧一个小圆点/小图标，右侧「更多>>」
- 跑马灯公告（`<marquee>`，现在用 CSS animation 模拟）
- 闪烁的 `NEW`、`HOT`、`推荐` 小标（当年是 GIF，现在用 CSS `animation: blink`）
- 访客计数器（黑底绿字或数字图片）、「您是第 N 位访客」、「当前在线 N 人」
- 友情链接区、站长公告、版权行、ICP 备案号、「推荐 IE5.5 以上 1024×768 浏览」
- 表格化的列表：标题 + 作者 + 人气 + 时间四列
- 表单：细边框输入框、灰色按钮或渐变按钮、验证码图片
- 分页：`上一页 [1] 2 3 4 下一页 共 N 页`

## 三、当年没有的（不要用）

圆角大卡片、卡片阴影、大留白、无衬线大标题、粘性导航、无限滚动、骨架屏、暗色模式切换、SVG 图标库、图片懒加载占位模糊、渐变彩色按钮、emoji 作为图标、移动优先的响应式。

## 四、现代产品 → 当年的对应物

| 现代 | 2003 年的对应 | 复刻要点 |
| --- | --- | --- |
| 小红书 / 微博 | 门户社区、个人主页、BBS | 笔记/帖子列表、盖楼留言、顶一下、精华置顶、积分等级 |
| 淘宝 / 拼多多 | 早期 C2C 交易站 | 宝贝列表、担保交易、卖家发货、双向信用评价（心/钻） |
| 微信 / 钉钉 | OICQ、MSN、网页聊天室 | 好友列表、聊天室（轮询或 SSE 模拟）、留言板、在线状态 |
| 抖音 / B 站 | 视频下载站、Flash 小游戏站 | 列表 + 详情页播放、评论盖楼、下载地址、分 P |
| Notion / 飞书 | 企业内网、Wiki、BBS | 文档列表、编辑器（UBB 而不是富文本）、权限、公告 |
| Spotify / 网易云 | 音乐盒、试听站、电台 | 歌单列表、试听（Web Audio 模拟当年的嵌入播放器）、排行榜 |
| 大众点评 | 生活服务黄页 | 分类目录、商户详情、网友点评打分 |
| 知乎 | 论坛问答版块 | 提问帖、回帖、加精、版主 |
| Google / 百度 | 极简搜索页 | 搜索框 + 结果列表、网页快照、分类目录 |

## 五、必须砍掉或替换的现代功能

| 现代功能 | 当年的处理 |
| --- | --- |
| 即时聊天 / 消息推送 | 留言板、站内短消息、聊天室（页面自动刷新） |
| 扫码支付 / 第三方支付 | 货到付款、邮局汇款、银行转账，或模拟的担保交易 |
| 手机验证码 | 图形验证码、密码提示问题 |
| 推荐算法信息流 | 编辑推荐、点击排行、最新发布 |
| 无限滚动 | 分页 |
| 视频号 / 直播 | 不做，或做成「视频下载」 |
| 第三方登录 | 只有本站账号 |
| 云同步 / 多端 | 单站点 + Cookie 记住我 |

## 六、当年的文案风格

- 称呼：会员、网友、站长、版主、贵宾（VIP）
- 动作：发表、灌水、盖楼、顶一下、送花、加精、置顶、锁帖
- 提示：「操作成功！页面将在 3 秒后自动跳转」「您还未登录，请先登录」「对不起，您没有权限访问该页面」
- 页脚：「本站所有内容均由网友发表，不代表本站立场」
- 公告用 ☆ ★ ◆ 等符号装饰，重要文字用红色加粗
