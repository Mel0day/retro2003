# 演示数据：让站点像运营了一两年

空站点是复古复刻最容易失败的地方——2003 年的门户最大的感觉就是「密密麻麻都是内容」。

## 规模参考

| 对象 | 数量 | 说明 |
| --- | --- | --- |
| 会员 | 20-60 | 名字要有年代感：`网虫2002`、`蓝色海洋`、`hz_leo`、`小丸子`；混一些拼音和英文名 |
| 主要内容 | 60-200 | 首页第一屏就要能填满 10 条以上 |
| 互动（留言/评价/回帖） | 100-2000 | 有互动痕迹的站才像活的 |
| 交易/订单类 | 40+ | 状态要铺开：进行中、已完成、已取消 |

## 时间分布

- 最近 3 天要有几条（首页顶部不能全是旧帖）
- 最近一个月密一些，往前逐渐稀疏，最早到一两年前
- 用固定种子的伪随机数生成时间，保证每次导入结果一致：

```js
let seed = 20030510;
const rnd = (n) => { seed = (seed * 1103515245 + 12345) % 2147483648; return Math.floor((seed / 2147483648) * n); };
const day = (d) => Math.round(now() - d * 86400 - rnd(40000));
```

## 内容本身

- 标题和正文要像当年的人写的：「秋季通勤穿搭 5 套」「宿舍能做的电饭锅蛋糕」「第一次买 MP3 求推荐」
- 出现当年的东西：MP3、Discman、诺基亚 3310、QQ 秀、MSN 签名、网吧、校内 BBS、《大话西游》VCD
- 别写现代词汇：短视频、扫码、直播、AI、云同步

## 配图

`scripts/fetch-seed-images.mjs`（参考 `sites/taobao2003`）从 Unsplash 搜图下载到 `seed/images/`，并把作者署名记进 `credits.json`；站点用 `/uploads/seed/xxx.jpg` 引用。图片随仓库分发，部署时不需要再下载。

## 幂等

`seedDemo(ctx, { onlyIfEmpty: true })` 必须做到：库里已有会员（或设置了 `demo_seeded` 标记）就直接返回，不写第二遍。否则重启一次数据翻倍，删光内容后重启还会因为会员重名直接崩溃。

## 演示账号

留一个 `demo` 账号，密码统一 `demo1234`，并且让它手上有「各种状态」的数据：待处理的、已完成的、能继续操作的。README 里写清楚。站长账号的密码只从环境变量来，不要写死。
